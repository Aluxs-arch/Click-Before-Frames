# Support / Dukungan

**EN:** Found a bug, a translation mistake, or a physics issue? Open an issue
(in English or Bahasa Indonesia) at
[github.com/Aluxs-arch/Click-Before-Frames/issues](https://github.com/Aluxs-arch/Click-Before-Frames/issues).
Please include your Geode version, GD version, platform, FPS, your *Before Frame*
settings (preset, lead mode, manual lead, separate-lead scales) and — if you can
— a screenshot of the **Show Debug Overlay** output (frame time, current step,
lead, clicks moved to step 0, latency saved). Pull requests for new
translations and fixes are welcome. Developer: **Aluxs** — GitHub **@Aluxs-arch**.

**ID:** Menemukan bug, salah terjemahan, atau masalah fisika? Silakan buka issue
(dalam bahasa Inggris atau Indonesia) di
[github.com/Aluxs-arch/Click-Before-Frames/issues](https://github.com/Aluxs-arch/Click-Before-Frames/issues).
Sertakan versi Geode, versi GD, platform, FPS, pengaturan *Before Frame* Anda
(preset, mode jeda, jeda manual, skala jeda terpisah), dan — kalau bisa —
screenshot **Overlay Debug** (interval frame, step saat ini, jeda, klik yang
pindah ke step 0, latensi yang dihemat). Pull request untuk terjemahan dan
perbaikan sangat diterima. Developer: **Aluxs** — GitHub **@Aluxs-arch**.
